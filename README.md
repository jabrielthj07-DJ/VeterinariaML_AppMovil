## Descripcion

APP Veterinaria M&L es una aplicacion movil diseñada para facilitar la gestion de la veterinaria, permitiendo consultar informacion de productos, controlar las existencias del inventario y visualizar reportes de ventas. Su objetivo es ayudar al personal a mantener la informacion organizada, dar seguimiento a las operaciones del negocio y contar con datos utiles para tomar mejores decisiones.

## Funcionalidades principales

- Inicio de sesion para usuarios autorizados.
- Consulta de productos y categorias.
- Consulta y seguimiento del inventario.
- Consulta de ventas totales y ticket promedio.
- Perfil de usuario.
- Configuracion de tema claro y oscuro.
